Simulación a 500 muestras/s. La señal no proviene de un dispositivo.

Los contadores representan gestos simulados, no clics de tu computador. Para contar una activación se exige reposo estable y después un estado activo estable. Modificar un control reinicia el armado. Los valores exactos de los umbrales pertenecen al reposo.

Tres formas de explorar

Hazle preguntas
a la señal.

01 / Clasificación

¿El mismo dato puede cambiar de estado?

Pulsa Fijar ADC en 2700. Mueve el umbral superior de 2500 a 2800. El dato no cambia; cambia la regla que lo interpreta.

02 / Ruido

¿Un pico breve debería contar?

Elige una señal ruidosa. Compara una estabilidad baja y una más alta. Observa cómo cambia la exigencia temporal para reconocer una activación.

03 / Una acción

¿Por qué no se repite sin parar?

Deja correr la señal con activaciones. Un estado sostenido cuenta una vez; el detector espera reposo estable antes de aceptar otra acción.

Lo que esta simulación no hace

Enseña el mecanismo.
No valida el hardware.

La onda se genera en este navegador. No usa Web Serial, no recibe datos de una persona ni modifica el firmware de un STM32. Tampoco reproduce la latencia completa de adquisición, USB y voz.

El eje temporal y la estabilidad usan una frecuencia nominal de 500 Hz. Para observar una señal real, GHOST Monitor necesita el equipo, un formato de datos compatible y permiso de puerto.
