Antes de empezar

Preguntas que importan.

¿GHOST detecta el movimiento de los ojos?

El software actual no incluye seguimiento ocular. Interpreta clics o una señal compatible que recibe de una interfaz externa. Usar un movimiento ocular como entrada requeriría un sensor y un acondicionamiento adecuados, además de validación individual.

¿Necesito el STM32 para probarlo?

No. Puedes usar GHOST con los clics del mouse, explorar este laboratorio o activar el modo demo de GHOST Monitor. La lectura de una señal física por USB sí requiere el dispositivo y un firmware compatible.

¿Ya es una solución validada para cualquier persona?

No se presentan resultados clínicos ni se garantiza un acceso universal. El software se ha probado con entradas y puertos simulados; la integración física y la adecuación a cada persona necesitan comprobación específica.

¿Cómo se plantea una implementación?

Partimos del contexto: quién va a usarla, qué entradas puede generar, qué hardware existe y quién acompañará el proceso. Puedes preparar una ficha de implementación, descargarla y compartirla mediante el canal que acuerdes con el proyecto.
