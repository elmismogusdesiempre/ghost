Antes de empezar

Lo que suelen preguntar.

¿GHOST detecta el movimiento de los ojos?

Por ahora no. El software no tiene seguimiento ocular: interpreta clics o una señal compatible que le llega desde otra interfaz. Para usar el movimiento de un ojo haría falta un sensor adecuado, preparar bien la señal y comprobarlo con cada persona.

¿Necesito el STM32 para probarlo?

No. Puedes usar GHOST con los clics del mouse, probar este laboratorio o activar el modo demo de GHOST Monitor. Solo necesitas el dispositivo y un firmware compatible si quieres leer una señal física por USB.

¿Ya está comprobado que funciona para cualquier persona?

No. No hay resultados clínicos ni prometemos que sirva para todos. Hemos probado el software con entradas y puertos simulados; conectarlo a hardware real y ajustarlo a cada persona requiere pruebas propias.

¿Cómo se plantea una implementación?

Empezamos por el contexto: quién lo va a usar, qué movimientos puede hacer, qué equipo hay y quién va a acompañar. Puedes llenar una ficha de implementación, descargarla y enviarla por el canal que acuerdes con el proyecto.
