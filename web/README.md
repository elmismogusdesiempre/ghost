# GHOST · Web de producto

Sitio de presentación independiente, construido con HTML, CSS y JavaScript sin dependencias de ejecución. El proyecto Vercel de esta web usa `web` como Root Directory. Los archivos de las aplicaciones existentes no se modifican.

## Rutas

- `/`: presentación y demostración de las tres etapas.
- `/producto/`: funciones, versiones y etapas.
- `/personas/`: acceso, acompañamiento y ejemplos de comunicación.
- `/ingenieria/`: documentación técnica detallada, decodificador y acumulador interactivos.
- `/laboratorio/`: señal irregular simulada, umbrales y estabilidad.
- `/proyecto/`: propósito social, propuesta comercial y estado de validación.
- `/implementacion/`: ficha local descargable y enlace opcional a una solicitud pública en GitHub.

El formulario no envía datos a un servidor. No hay precios, testimonios ni resultados clínicos inventados. La web distingue claramente simulación y hardware. No se presenta seguimiento ocular como función implementada.

Las ilustraciones y el símbolo de marca son SVG originales de esta web, en `assets/images`. La marca representa dos entradas dentro de un espacio de conversación de esquinas rectas. Archivo se aloja localmente. La fuente de cuerpo es un subconjunto estático derivado de IBM Plex Sans, redistribuido como GHOST Text para respetar el nombre reservado del original. Se conservan ambas licencias OFL en `assets/fonts`.

El laboratorio procesa una señal artificial a 500 muestras/s nominales. Sus contadores nunca activan las aplicaciones de comunicación. Incluye pausa, muestra fija de 2700 y perfiles de señal. Las preferencias de lectura se guardan únicamente bajo `ghost_product_reading_v1`.
