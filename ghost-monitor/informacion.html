Uso de la aplicación

La aplicación continúa siendo pública, gratuita y sin autenticación obligatoria. Los avisos no modifican la comunicación, el barrido, la voz ni los datos guardados en el navegador.

  • Ctrl + Alt + M abre configuración; el atajo se puede cambiar a G o Y.
  • Ctrl + Alt + 1, 2 o 3 selecciona una etapa.
  • En GHOST Monitor, Ctrl + Alt + U habilita el ajuste rápido y Ctrl + F1 abre la ayuda.
  • La conexión STM32 y el modo demo se administran desde Monitor STM32. La señal y el firmware no se modifican por este aviso.

Privatizar un repositorio no elimina copias o forks anteriores ni revoca permisos concedidos previamente. El HTML, CSS y JavaScript que el navegador necesita para ejecutar GHOST pueden inspeccionarse; la privacidad del repositorio no impide toda copia.
